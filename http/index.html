Hydrogen Http-Server

Hydrogen is my own implementation of an http-server written in C/C++. I do not claim that that hydrogen is a fully compliant implementation of the HTTP/1.1 protocol, for this is a work in progress.

The purpose of this page is to share the lessons learned from attempting to implement an http-server just from the specs RFC9110 and RFC9112 and the Linux man pages. I did not use AI to generate the server code and I did not ask AI either for any kind of advice or help. The code is mostly the result of experimentation and borrowing ideas from open-source projects such as the xserver; to give you an idea the router code is loaded dynamically in the same way the xserver loads input drivers.

Part of the motivation for this project came from Lane's boot.dev implementing an http-parser in Golang. I did watch the first 30 minutes of the video featuring the Primeagen. I always enjoy his energy but this time I decided that I would watch only after doing the hard work myself to learn by comparing his approach of developing the http-parser to my own.

Compiling Hydrogen

All that you need to compile the hydrogen source code into a binary is the GNU Compiler Collection (GCC) along some standard libraries that should be present in most Linux distributions.
